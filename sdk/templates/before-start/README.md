# {{title}}

An OrbTorrent extension that holds downloads bigger than a size you choose,
until you decide to start them.

## Develop

```sh
npm install
npm test        # run the tests in tests/
npm run dev     # load it into OrbTorrent and rebuild on every save
```

`npm run dev` needs OrbTorrent open, with **Allow development extensions** on
(on the Develop tab of OrbTorrent's **Extensions** page). See AGENTS.md for the API and the rules.
