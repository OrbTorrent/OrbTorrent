# OrbTorrent Extensions

The extension docs are at **[orbtorrent.com/docs/extensions](https://orbtorrent.com/docs/extensions)**:
how to build, test, debug and share an extension, the API, the `orb`
command, the manifest, and the security model.

For language models and coding agents, the same docs are in one file at
[orbtorrent.com/docs/extensions/llms-full.txt](https://orbtorrent.com/docs/extensions/llms-full.txt),
and every page is Markdown at its address plus `.md`.

Their source is in this repository, in
[`website/src/content/docs/docs/extensions`](../../website/src/content/docs/docs/extensions),
so a change to the SDK and its docs go in the same pull request.
