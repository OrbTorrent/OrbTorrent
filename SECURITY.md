# Security

Please report security problems privately, by email to
`help@orbtorrent.com`, with "Security" in the subject. Don't open a public
issue for them.

Say what the problem is, how to reproduce it, and which OrbTorrent version and
macOS version you saw it on. A fix comes through OrbTorrent's automatic
updates as soon as it's ready. Tell us if you'd like to be credited in the
release notes.

This covers the app, its bundled engine, the extension host, the official
extensions in `extensions/`, the extension SDK on npm (`@orbtorrent/api` and
`@orbtorrent/create-extension`), and the update feed at
`updates.orbtorrent.com`. Problems in qBittorrent or libtorrent themselves are
best reported to those projects too.

Only the newest version of OrbTorrent gets security fixes.
