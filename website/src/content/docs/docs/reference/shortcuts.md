---

OrbTorrent is a menu bar app, so its menus show in your Mac's menu bar while its window is open.

## OrbTorrent

| Command | Shortcut |
|---|---|
| About OrbTorrent | |
| Check for Updates… | |
| Settings… | <kbd class="key">⌘,</kbd> |
| Quit OrbTorrent | <kbd class="key">⌘Q</kbd> |

## File

| Command | Shortcut |
|---|---|
| Open Torrent File… | <kbd class="key">⌘O</kbd> |
| Add Magnet Link… | <kbd class="key">⌘U</kbd> |
| Add from Clipboard | <kbd class="key">⇧⌘V</kbd> |
| Import From › Transmission… or qBittorrent… | |
| Install Extension… | |

**Add from Clipboard** adds a magnet link, or a link to a `.torrent` file, that you've copied. **Install Extension…** shows while extensions are on.

## Downloads

| Command | Shortcut |
|---|---|
| Pause All | <kbd class="key">⌥⌘.</kbd> |
| Resume All | <kbd class="key">⌥⌘R</kbd> |
| Show in Finder | <kbd class="key">⌘R</kbd> |
| Remove… | <kbd class="key">⌘⌫</kbd> |
| Show Inspector or Hide Inspector | <kbd class="key">⌘I</kbd> |

**Show in Finder** and **Remove…** act on the downloads selected in the library.

## Help

| Command | |
|---|---|
| What's New in OrbTorrent | The release notes for the version you have. |
| Report a Problem… | A report to send from your own mail app. [Report a problem](/docs/help/report-a-problem) explains. |

## In the window

| Do this | To |
|---|---|
| <kbd class="key">⌘V</kbd> | Add a magnet link, or a link to a `.torrent` file, that you've copied. |
| Drag a `.torrent` file onto the window | Add it. |
| Double-click a download | Open it. |
| <kbd class="key">⌘A</kbd> | Select every download in the list. |
| <kbd class="key">⌫</kbd> or <kbd class="key">⌘⌫</kbd> | Remove the selected downloads, after asking. |
| Right-click a download | Its menu: Open, Show in Finder, Pause, Download Sequentially, Copy Magnet Link, More and Remove. |

## When OrbTorrent asks about a download

| Key | Does |
|---|---|
| <kbd class="key">↩</kbd> | **Download**, or **Download Anyway** when a check found a problem. |
| <kbd class="key">esc</kbd> | **Cancel**. |

## In the menu bar panel

| Do this | To |
|---|---|
| Click a download | See its files. |
| Right-click a download | Open, Show in Finder, Pause, Copy Magnet Link, Show in OrbTorrent or Delete. |
| **More (…)**, then <kbd class="key">⌘,</kbd> | Open Settings. |
| **More (…)**, then <kbd class="key">⌘Q</kbd> | Quit OrbTorrent. |
